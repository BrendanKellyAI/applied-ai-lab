Using the Fenwick cooker hood timer

The Fenwick cooker hood’s timer keeps the fan running for 10 minutes, then switches it off automatically. Use it after cooking to help clear lingering steam and smells.

To set the timer:
1. Switch on the fan and select your preferred speed.
2. Press the timer button once to start the 10-minute countdown.
3. Leave the hood running; the fan will stop when the countdown ends.

To cancel the countdown, press the timer button again. You can also switch the fan off manually if you no longer need extraction.

This is a run-on timer, not a delay-start function: it does not switch the hood on at a later time.
