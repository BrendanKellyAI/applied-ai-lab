# Keel washing machine: power cut during use

If your Halvard Home Keel washing machine stops during a power cut, switch it off at the wall socket if you can reach it safely with dry hands. Leave the door closed and do not force it open, as water may remain inside.

When power returns:

1. Switch the wall socket back on.
2. Check whether the machine is ready to continue the interrupted wash.
3. If it does not continue, select a suitable wash programme and start it again.

If you need to remove the laundry, run a drain programme first. Wait until the drum has stopped and the door lock releases before opening the door.

If the machine remains unresponsive, contact Halvard Home support.
