Keel washing machine lint filter notice

Stop using lint filters from batch 1807 with the Keel washing machine, and return them for a refund.

Halvard Home is asking customers to check the batch marking on their lint filter packaging. If the marking matches the affected batch, remove the filter only when the appliance is switched off and safe to handle. Keep the filter aside and contact Halvard Home customer support for return instructions and refund help. If the batch marking is missing or unclear, please contact customer support before using the filter.

We are sorry for the inconvenience and thank you for your care and understanding.
