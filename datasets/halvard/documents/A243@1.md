Using the Corra hob timer

The Corra induction hob’s cooking timer switches off the selected cooking zone when the set time ends. Set a separate timer for each zone you want to control.

Place a suitable pan on the hob, select the cooking zone and choose a heat level. Touch the timer control, then use the plus or minus controls to set the cooking time in minutes. For example, setting 10 minutes switches that zone off after 10 minutes.

To change the time, select the same zone and touch the timer control again. To cancel its timer, reduce the time to zero.

The timer does not replace supervision. Stay nearby while cooking, especially when heating oil or fat.
