Tessa dishwasher running slowly or cleaning poorly

If your Tessa dishwasher takes longer than expected or leaves dishes dirty, start with these checks.

Switch off and unplug the dishwasher before cleaning. Remove food scraps from the filter and rinse it under running water. A blocked filter can restrict water flow and reduce cleaning performance. Refit it securely before using the machine.

Check that dishes do not block the spray arms. Turn each arm gently by hand to make sure it moves freely. Avoid stacking items tightly together.

Use dishwasher detergent and choose a programme suited to the load. Economy programmes can take longer than standard washes.

If performance stays poor after these checks, contact Halvard Home support. Stop using the dishwasher if it leaks.
