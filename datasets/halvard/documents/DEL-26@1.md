Brio kettle lint filter notice

Stop using lint filters from batch 7105 with the Brio kettle, and return them for a refund.

Halvard Home is asking customers to check the batch marking on their lint filter packaging. If the marking matches the batch shown above, please remove the filter only when the kettle is unplugged and completely cool. Do not try to repair or modify the filter.

Contact Halvard Home customer support for help arranging your return and refund. If the packaging is missing or the marking is unclear, stop using the filter and ask customer support for advice.

We apologise for the inconvenience and appreciate your cooperation.
